# orbAudio Genesis Documentation Set

This folder provides the structured technical documentation package required for firmware continuity, BOM alignment, and release clarity.

## Document Index

- `FIRMWARE_ARCHITECTURE.md` — firmware structure, runtime flow, and module responsibilities.
- `PIN_CONFIGURATION.md` — sensor/audio pin mapping and interface ownership.
- `COMMUNICATION_PROTOCOLS.md` — electrical and software communication interfaces.
- `HARDWARE_INTEGRATION_NOTES.md` — integration constraints and module-level notes.
- `SETUP_AND_DEPLOYMENT.md` — environment setup, build, flash, and verification steps.
- `DEBUGGING_AND_TROUBLESHOOTING.md` — debug flow and common issue resolution.
- `BOM_ALIGNMENT.md` — firmware-to-BOM alignment, dependencies, and substitution tracking.
- `FIRMWARE_VERSIONING_AND_RELEASES.md` — versioning policy, stable/experimental labeling, and release process.

## Scope

These documents are written so another embedded systems engineer can continue development without material disruption.
